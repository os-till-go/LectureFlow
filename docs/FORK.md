# Windows toy fork

本分支是 [os-till-go/LectureFlow](https://github.com/os-till-go/LectureFlow/tree/windows-toy) 中独立维护的 Windows 实验项目，源自 [lotus116/LectureFlow](https://github.com/lotus116/LectureFlow)。不作为上游 Mac 产品的 Windows 正式版，不要求上游合并或维护本分支。

## 2026-11-13 方向调整

用户确认转为自用 fork，并关闭上游 [PR #6](https://github.com/lotus116/LectureFlow/pull/6)。Windows 独立开发不改变上游 main，后续只按需要人工挑选上游修复，不自动合并全部更新。原 PR 分支保留用于追溯，后续工作在 `windows-toy`。

- CPU 优先，先把录音安全、导入、课后转写与导出做可靠。实时字幕留作实验，不承诺课堂可用或与 Mac 功能对齐。
- 课堂不依赖独显，不以新增 GPU 加速作为默认方向。模型权重保存在硬盘，现有 Windows 推理使用系统 RAM。
- 当前默认仍是英语专用 Whisper tiny.en + Marian，混合语种录音的适用性不足；尚未换成新的小模型。小不等于正确、低功耗或安静。
- Qwen3-ASR 1.7B CPU 后端保留为可选离线对照，不做课堂主力。已有一次 180 秒原音约 210 秒纯识别的结果不代表实时、续航或风扇噪声验收。
- 项目仍保留录音强退恢复、中断提示和原音保护要求。“玩具”定位不放松数据保护。

## 下一个有边界的实验

只选一个多语种 CPU 小模型候选，用固定原音分别检查英文和中英混合内容，再与现有配置对照。先记录耗时、系统 RAM、执行异常和已核实的错词；功耗、温度、风扇噪声和电池表现另做实机检查。不会先下载一批大模型，也不以模型输出充当人工真值。

模型选型与默认值尚未改变，实验未开始。本次只整理 fork、文档和分支，不声称新增模型已达到课堂要求。

## 维护与运行

当前入口和已知限制见 [Windows 说明](WINDOWS.md)。上游 PRODUCT、设计编号与 Mac 发布文档保留追溯，不作为 Windows toy 的功能完成清单或自动发版授权。继承的 Mac 代码与工作流保留，不发布 Mac 附件，不冒用上游版本已发布的信息给本分支背书。

只提交源码、测试与不含课堂内容的结论。录音、课件、逐字转写、模型权重和个人路径保留在本机忽略目录。发现可独立贡献的上游通用缺陷时另行讨论小 PR，不重新提交整套 Windows 移植。
